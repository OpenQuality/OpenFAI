## 二、环节详细说明

### 1. 零件管理
**功能**：管理零件主数据
- 创建/编辑零件信息
- 上传 CAD 文件、DWG/DXF 图纸、PDF 文档
- 关联客户信息、供应商信息
- 版本管理

**产出**：零件基本信息 + 图纸文件

---

### 2. OCR 识别（可选）
**功能**：从图纸中自动提取尺寸标注
- 支持 PDF、DWG、PNG、JPG 等格式
- 自动识别尺寸值、公差信息
- 提取 GD&T（形位公差）
- 生成尺寸列表供检验计划使用

**产出**：尺寸数据清单（CADExtraction + Dimension）

---

### 3. 检验计划
**功能**：定义检验项目和检验标准
- 从 OCR 结果一键生成检验计划
- 或手动创建检验特性
- 设置检验项目：
  - 标称值（Nominal Value）
  - 上公差（Upper Tolerance）
  - 下公差（Lower Tolerance）
  - 测量设备
  - 检验方法

**产出**：检验计划（InspectionPlan）+ 检验特性（InspectionCharacteristic）

---

### 4. SOP（标准作业程序）- ⭐ 新增环节
**功能**：关联检验作业指导
**模型**：`parts.models.SOPDocument`

| 文档类型 | 说明 |
|---------|------|
| SOP | 标准操作程序 |
| 作业指导书 | WI - Work Instruction |
| 检验指导书 | Inspection Guide |
| 控制计划 | Control Plan |

**关联关系**：
```
检验计划 ──┬── SOPDocument（控制计划）
           ├── ControlRequirement（控制要求）
           └── RiskPoint（风险点）
```

**产出**：检验作业指导文档

---

### 5. 测量批次
**功能**：录入测量数据并自动计算过程能力
**模型**：`measurements.MeasurementBatch`

#### 自动计算指标：
| 指标 | 公式 | 说明 |
|------|------|------|
| **Cp** | (USL-LSL)/(6σ) | 过程能力指数 |
| **Cpk** | min(Cpu, Cpl) | 过程能力指数（考虑偏移） |
| **Cpu** | (USL-μ)/(3σ) | 上限能力指数 |
| **Cpl** | (μ-LSL)/(3σ) | 下限能力指数 |
| **σ** | 标准差 | 过程标准差 |

#### 判定规则：
| Cpk 范围 | 判定 | 颜色 |
|----------|------|------|
| Cpk ≥ 1.67 | 优秀 | 🟢 绿色 |
| 1.33 ≤ Cpk < 1.67 | 良好 | 🔵 蓝色 |
| 1.00 ≤ Cpk < 1.33 | 合格 | 🟡 黄色 |
| Cpk < 1.00 | 不合格 | 🔴 红色 |

**产出**：测量数据 + Cp/Cpk 统计结果

---

### 6. 统计分析模块
**功能**：可视化展示过程能力分析
**模型**：`measurements.StatisticalAnalysis`

#### 统计图表：
1. **直方图** - 数据分布
2. **控制图** - X̄-R 控制图
3. **趋势图** - 测量值随时间变化
4. **超出公差分析** - 不合格点标记

#### 统计指标：
- 样本数量（n）
- 平均值（μ）
- 标准差（σ）
- 最大值、最小值
- 极差（R）
- Cp、Cpk

**产出**：统计分析报告

---

### 7. 检验报告
**功能**：生成符合标准的检验报告
**模型**：`reports`

支持标准：
- AS9102（航空航天首件检验）
- PPAP（生产件批准程序）
- IATF 16949（汽车行业）

**报告内容**：
- 零件信息
- 检验结果汇总
- 测量数据表
- Cp/Cpk 分析结果
- 结论与建议

---

### 8. 审批流程
**功能**：多级审批与电子签名
**模型**：`workflows`

#### 审批节点：
1. 检验员提交
2. 质量工程师审核
3. 质量经理批准
4. 发布归档

#### 功能：
- 电子签名
- 审批意见
- 历史追溯
- 状态跟踪

## 四、Cp/Cpk 计算详解

### 公式说明

```
          USL - LSL
Cp  =  ─────────────
           6σ

           USL - μ        μ - LSL
Cpk = min(────────,  ────────)
            3σ           3σ

其中：
  USL = Upper Specification Limit (上限规格)
  LSL = Lower Specification Limit (下限规格)
  μ   = 过程平均值 (Mean)
  σ   = 过程标准差 (Standard Deviation)
```

### 计算时机

| 触发条件 | 自动计算 |
|---------|---------|
| 手动录入测量数据 | ✅ 保存时计算 |
| 批量导入数据 | ✅ 导入完成计算 |
| 测量批次完成 | ✅ 调用 complete 时计算 |
| 测量记录修改/删除 | ✅ 重新计算 |

### 判定标准

| 指标 | 等级 | 说明 |
|------|------|------|
| Cp = Cpk | 理想状态 | 过程中心无偏移 |
| Cp > Cpk | 存在偏移 | 需要调整过程中心 |
| Cp < Cpk | 数据异常 | 检查数据质量 |

| Cpk 值 | 过程能力 | 建议措施 |
|--------|---------|---------|
| Cpk ≥ 2.0 | 六西格玛级别 | 考虑降低成本 |
| 1.67 ≤ Cpk < 2.0 | 优秀 | 保持当前状态 |
| 1.33 ≤ Cpk < 1.67 | 良好 | 轻微改进 |
| 1.00 ≤ Cpk < 1.33 | 合格 | 需要改进 |
| Cpk < 1.00 | 不合格 | 立即采取措施 |

## 六、流程改进建议

### 6.1 SOP 与检验计划深度集成

**建议**：
1. 检验计划创建时自动关联 SOP 模板
2. 根据零件类型推荐对应的检验指导书
3. SOP 文档版本与检验计划版本同步

**实现方式**：
```python
# 检验计划创建时自动生成关联
def create_inspection_plan(part):
    sop = SOPDocument.objects.filter(
        part=part,
        document_type='INSPECTION_GUIDE',
        status='PUBLISHED'
    ).first()
    
    if sop:
        plan.sop_document = sop
        plan.save()
```

### 6.2 Cp/Cpk 预警机制

**建议**：
1. 设置 Cpk 预警阈值
2. 自动发送通知
3. 生成改进建议

**实现方式**：
```python
# 保存测量数据时检查
def check_cpk_threshold(characteristic, cpk):
    if cpk < 1.0:
        send_alert(f"Cpk {cpk} 低于阈值！")
    elif cpk < 1.33:
        send_warning(f"Cpk {cpk} 需要改进")
```

### 6.3 自动生成控制图

**建议**：
1. 测量批次完成后自动生成 X̄-R 控制图
2. 标注异常点
3. 保存为图片附件
